# OpenMontage Editing Stock Library v3

Carries forward **all v2 original assets**, presets, scripts, and metadata and adds a script-aware edit planner with optional local embedding search, transcript timing support, repeat penalties, confidence scoring, edit decision list output, and automated unit tests. See `documentation/V3_SEMANTIC_EDIT_PLANNER.md`.

This library is not connected to your OpenMontage repository and no model weight training has taken place. External provider footage remains unbundled.
